# بوت عيادة الدكتور حسام العايدي (Render + MongoDB)

## محتويات المجلد
- `index.js` : كود البوت الكامل (نقطة التشغيل)
- `package.json` : الحزم المطلوبة
- `Dockerfile` / `.dockerignore` : تشغيل البوت على Render مع Chromium
- `letterhead.jpeg` : ورقة العيادة المستخدمة في فاتورة الـ PDF
- `.env.example` : أسماء المتغيرات المطلوبة في Render

## خطوات النشر
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (احذف الملفات القديمة: app.py, gmail-auth.js, requirements.txt, packages.txt).
2. في Render ← Environment أضف المتغيرات الموجودة في `.env.example`.
3. في MongoDB Atlas ← Network Access اسمح بـ 0.0.0.0/0.
4. انشر، ثم افتح الرابط الرئيسي `/` لمتابعة الحالة، و `/qr` لمسح رمز واتساب.
5. لا تعد النشر قبل ظهور `remote_session_saved` في اللوج (بعد ~5 دقائق من الاتصال).

## أوامر الواتساب (للإدارة)
- `استعلام` : القائمة الرئيسية
- `ربط جوجل` ثم `كود جوجل [الرابط]` : تجديد صلاحيات جوجل
- `اختبار التقرير` : تجربة تقرير الساعة 11 (يصلك أنت فقط)
- `تدقيق اسم المريض` : عرض حركات مريض في الوارد
- خيار 9 في القائمة : إضافة / تعديل بيانات المرضى

## أمان
لا ترفع `credentials.json` أو `token.json` أو أي مفاتيح إلى المستودع. استخدم متغيرات Render.
